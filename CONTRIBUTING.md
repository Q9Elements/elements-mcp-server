# Contributing

This repository packages the skills, documentation, and client packaging for the Elements MCP server, a hosted service operated by Elements.cloud. Its contents mirror the deployed service, so we are not accepting external pull requests; pull requests may be closed without review.

If you have something for us:

- **Security issues**: report privately per [SECURITY.md](SECURITY.md); please don't open a public pull request or issue.
- **Problems using the server**: start with [troubleshooting](docs/troubleshooting.md), then reach out to your usual Elements contact.
- **Feedback and suggestions**: through your Elements contact; your feedback genuinely shapes what ships next.
