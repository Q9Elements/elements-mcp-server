An Elements Model Context Protocol (MCP) playbook is a separate plugin that guides one well-defined Salesforce process from start to finish using real evidence from your org in Elements. It works through stages you can pause and resume, includes points where a person makes decisions, and hands back analysis and deliverables such as stories. A playbook analyzes only; you make every change in Salesforce.

A skill answers a question or does one task. A playbook guides a multi-stage engagement with decision points and saved progress.

What you need

  • Install and connect the core elements plugin to the Elements MCP server. Each playbook is a plugin that brings its own agents and scripts along with its skill; it adds no server or app of its own. See 'Connect your AI assistant to Elements' for setup steps.
  • Python 3 must be available where the playbook runs scripts.
  • Each playbook page lists its requirements.

Install a playbook

Playbooks are not included in elements-core-skills.zip and cannot be installed as loose skills, so install each playbook as a plugin.

Claude Code

Add the Q9Elements/elements-mcp-server marketplace if you have not already, then run:

/plugin install elements-remove-unused-apex@elements

For Data Load Impact, run:

/plugin install elements-data-load-impact@elements

For Elements Map and Design, run:

/plugin install elements-map-and-design@elements

For Analyze Change Impact, run:

/plugin install elements-change-impact@elements

Claude Desktop and claude.ai

Open 'Customize' > 'Plugins', then install the playbook from the Q9Elements/elements-mcp-server marketplace under 'Yours' or 'Discover'.

Codex

Add the Q9Elements/elements-mcp-server marketplace if you have not already, then run:

codex plugin add elements-remove-unused-apex@elements

For Data Load Impact, run:

codex plugin add elements-data-load-impact@elements

For Elements Map and Design, run:

codex plugin add elements-map-and-design@elements

For Analyze Change Impact, run:

codex plugin add elements-change-impact@elements

ChatGPT

  1. Upload the plugin package elements-remove-unused-apex.zip from the repository's dist folder.
  2. The core plugin provides the Elements app; you do not need to add an app separately.

Cursor, VS Code, and other tools

Run this command, then select the playbook:

npx plugins add Q9Elements/elements-mcp-server --target <tool>

Playbooks

  • Remove Unused Apex: find the Apex your Salesforce org can safely remove. It is tested with Claude command-line interface (CLI) and Cowork, ChatGPT (Work), and Codex CLI. See 'Remove Unused Apex'.
  • Data Load Impact: plan a Salesforce data load, including what it fires, safety controls, and an ordered backlog. It is tested with Claude command-line interface (CLI) and the Claude app. See 'Data Load Impact'.
  • Elements Map and Design: map and design your Salesforce business architecture as Elements diagrams. It is tested with Claude command-line interface (CLI). See 'Elements Map and Design'.
  • Analyze Change Impact: assess a proposed Salesforce automation or schema change and prepare an impact report with a draft delivery backlog. It is tested with Codex command-line interface (CLI). Other tools are untested. See 'Analyze Change Impact'.
