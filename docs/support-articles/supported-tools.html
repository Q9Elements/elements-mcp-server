The Elements Model Context Protocol (MCP) server exposes 56 tools. Your assistant usually selects the right tool from your request. Which tools you see depends on the Spaces you authorize. Elements checks role requirements, such as Space admin or Author, and access to a reference model, diagram, or view when a tool is called; without the required access, the call is refused with access_denied.

The required inputs column lists the key fields each tool needs. Read tools that support file delivery return a file only when a reply is larger than the 30,000-character response budget, unless their rows always come as part files.

These labels describe the MCP (Model Context Protocol) annotation each tool sends. Read-only means readOnlyHint: true; Writes to Elements means readOnlyHint: false and destructiveHint: false; Destructive in Elements means readOnlyHint: false and destructiveHint: true. Whatever its label, every tool reads and changes only data stored in Elements, the Elements database: diagrams, MetaFields, saved views, proposed nodes, Spaces, and this connection's authorization. No tool writes to, deploys to, or deletes anything in a Salesforce org.

  • Replaces the draft of a diagram with an edited copy. Your assistant first shows you what would be replaced and only goes ahead after you confirm. It changes the draft only; publishing stays with a person in Elements.
  • Can remove activities, lines, notes and text boxes from one level of a diagram, along with the attachments and links on a removed activity. For a large removal, or one that would take away a sub-process beneath an activity, your assistant must first ask you to confirm. A removed sub-process goes to the Elements recycle bin, and Elements keeps a history entry of the level before the assistant's first change.
  • Removing a picklist option, or narrowing which metadata a MetaField applies to, permanently deletes those values wherever they're used. Your assistant first shows you how many items would lose a value and only goes ahead after you confirm.
  • Disconnects your assistant from Elements. It deletes no data; you reconnect by signing in again. Your assistant asks you to confirm first.

Large results

Six tools always return rows as downloadable part files: get_dependencies, get_access, run_code_search, list_metadata_changes, list_metadata_by_criteria, and get_metadata_source. They use newline-delimited JSON or comma-separated values where supported. Manifest mode returns counts without rows where available. For file-only tools, delivery does not change row files; five accept it for oversized manifest replies, while list_metadata_changes does not accept it. Each reply states how long its links last (expiresInSeconds); call again for fresh links.
