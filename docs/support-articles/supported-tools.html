Your AI assistant uses a set of underlying tools to answer questions through Elements. This article lists them for reference; you don't need to call them by name, since the skills described in 'What you can do with Elements in your AI assistant' choose the right one automatically.

Prerequisites

  • MCP access is a licensed feature that Elements enables for your Space.

Every tool respects your existing Elements permissions: a tool never returns more than you could already see in the Elements app. The set of available tools grows over time as Elements adds new skills.

Only a small set of tools write anything (the Read/Write column below shows which). There is no delete tool, and no tool ever mutates Salesforce itself; however, update_metafield can irreversibly remove MetaField values held in Elements when applicability is narrowed or options are removed, and set_metafield_values can clear values, so follow the counting-before-destructive-edit recipe in the elements-metafields skill before making those changes.

Some tools are only available on certain Elements plans, such as Pro or Enterprise, or to users with a required role. A tool that no authorized Space makes available through its plan, licenses, and your role won't appear in your assistant's tool list at all; if you call a visible tool in a Space that doesn't qualify, or without the required rights to the specific resource, your assistant lets you know.
