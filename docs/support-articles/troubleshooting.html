If your AI assistant can't connect to the Elements Model Context Protocol (MCP) server, or something isn't behaving as expected, start here.

Prerequisites

  • You've followed the steps in 'Connect your AI assistant to Elements'.

Common issues

I can't connect, or no Spaces appear

The most common cause is that the Space isn't licensed for the MCP server yet. MCP is included in Advanced Metadata Management, or in Core Metadata Management with the Agentic Org Management add-on, and Elements enables it per Space. If a Space you expect to see is missing from the consent screen, it isn't licensed yet; once it is, reconnect and it will appear.

I'm stuck in a sign-in loop

Clear your assistant's saved Elements authorization and try connecting again. In most clients this is an option in the same menu where you added the connection; look for 'Disconnect' or 'Remove server' before reconnecting.

I get a 401 or 405 error when I open the URL

The Elements MCP endpoint only accepts signed-in POST requests, which your client's MCP library sends automatically. A plain browser visit sends a GET request instead, so you'll see an error: 401 Unauthorized if you're not signed in, or 405 Method Not Allowed if you are. Either way, this is expected and doesn't mean the service is down; connect through a supported client instead of opening the URL directly.

I get a 'too many requests' or 'server busy' message

To keep the service responsive for everyone, each connection is rate-limited and can run up to 20 requests at the same time; the server as a whole also has a limit and may reply 'server busy' under heavy load, and diagram changes and exports (manage_diagram, create_map, create_map_from_template, import_diagram, export_diagram) run one at a time on each server, so one sent while another is being saved may get 'server busy' too. Your assistant will report this as a rate limit (rate_limited), too many requests at once (too_many_concurrent_requests), or a busy server (server_busy), and each one says how many seconds to wait. Wait the full time before trying again; retrying sooner won't work, but it won't extend the pause either. Then ask your assistant to make fewer requests in parallel.

A large request times out

Large-result behavior depends on the tool. Six tools return rows as part files, while other read tools answer inline and may move oversized values to a file or shorten a list with a continuation hint. If a request times out, narrow the search, filter, or item selection and try again. See 'Supported tools in the Elements MCP server'.

I have access to more than one Space

If your account belongs to more than one Space, Elements asks you to choose which one (or ones) the connection can use when you first sign in. To change which Spaces a connection can use, revoke it and reconnect; see 'MCP security & admin controls'. When no Space is active, Elements uses your eligible default Space if you consented to it, or else the one eligible Space you consented to if there is exactly one; otherwise, the call returns active_space_required. If none of the Spaces you consented to can be used, every request is refused except disconnecting the connection. A Space named explicitly must also be authorized and enabled for the MCP server. Ask your assistant to switch Spaces at any time, for example: "Switch to the example project Space."

I used the wrong instance host

Elements runs in more than one location, so an endpoint that works for one Org may not work for another. Always match the URL shown in your browser when you're logged into Elements to the endpoint in the table in 'Connect your AI assistant to Elements'; never guess based on location.

ChatGPT says a plugin upload is a duplicate

The plugin name can remain on your account after you uninstall it. Log out of ChatGPT and back in. If ChatGPT still refuses the upload, the name is held by an earlier upload.

A plugin, its skills, or its tools don't appear in ChatGPT

After you upload or connect a plugin, log out of ChatGPT and back in.

Codex skills aren't listed

Run /skills and turn on the Elements skills you need. Invoke a skill with $, for example $elements-spaces.

Claude Desktop or claude.ai shows ${user_config.apiHost} in the connector URL

Replace ${user_config.apiHost} with your Elements host. See the Claude Desktop / claude.ai section in 'Connect your AI assistant to Elements' for the full steps.

FAQs

Is my data stored outside Elements? No. The MCP server reads from the same Elements data your account can already access; no additional copy of your data is created or stored by the connection itself.

Which AI assistants are supported? Any assistant whose MCP client supports remote MCP servers with the MCP standard's secure sign-in (OAuth 2.1 with PKCE). Elements has been tested with Claude (CLI and Cowork), Codex CLI, ChatGPT (Work), and Cursor.

My assistant says it doesn't have a tool, or can't do something these articles describe. The tool list depends on the plan and license flags of your authorized Spaces. Role requirements, such as Space admin or Author, are checked when you call a tool; a call without the required role is refused with access_denied. If your connection covers several Spaces, a tool available through one Space can return feature_not_enabled for a missing plan or feature flag, or access_denied for a missing Elements role or resource access. A feature-flag refusal may tell your assistant to check Spaces with get_space_context and switch with set_active_space; role and resource refusals do not always include that hint. Requires a Pro Plus space means the Space needs a Core or Advanced Metadata Management plan. Requires Org AI Analysis add-on means the Space needs the Automation & Execution Intelligence add-on on Core Metadata Management; Advanced Metadata Management includes it. For Requires Analytics 360 add-on, quote the returned message verbatim and contact your Elements representative, who can match it to your plan. For any other refusal, contact your Elements representative, who can match it to your plan. See 'Supported tools in the Elements MCP server'.

How do I revoke access? Removing the server from your client's config stops that client using it, but the server-side connection remains until its refresh token expires, 30 days after its last refresh. A connection used at least monthly stays signed in. To revoke it immediately, go to your Elements profile, select the 'Connected apps' tab, find the connection, and click 'Revoke'. Space administrators can remove their Space from a connection. This takes effect immediately.
